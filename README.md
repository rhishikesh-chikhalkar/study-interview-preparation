### 🧠 Phase 0 — Computer Science Fundamentals

> **Focus**: Building problem-solving intuition, coding speed, and pattern recognition. At 5+ YOE, you should solve mediums in ~15 min and recognize patterns instantly.

<details>
<summary><b>🔍 Expand/Collapse DSA Sub-topics</b></summary>

#### 📐 Complexity Analysis (Senior Depth)

- [ ] **Big O Notation**: Time/Space complexity trade-offs, 🎯 analyzing nested loops and recursive calls
- [ ] **Amortized Analysis**: Dynamic array resizing, hash table operations, union-find path compression
- [ ] **Average-Case vs Worst-Case**: QuickSort analysis, hash collisions, probabilistic data structures
- [ ] **Master Theorem**: Solving recurrence relations (T(n) = aT(n/b) + f(n)), recognizing common patterns
- [ ] **Space-Time Trade-offs**: 🎯 When to trade memory for speed and vice versa — hash maps vs sorting, memoization vs tabulation

#### 🌲 Core Data Structures

- [ ] **Arrays & Strings**: 🎯 Hash map mapping, sliding window, prefix sums, Kadane's algorithm, in-place manipulation
- [ ] **Linked Lists**: Single, Double, Circular, 🎯 Fast/Slow pointers (cycle detection, middle finding), merge sorted lists
- [ ] **Stack & Queue**: 🎯 Monotonic stack (next greater element), Deque patterns, min-stack, stack-based parsing
- [ ] **HashMap & HashSet**: Collision resolution (chaining vs open addressing), amortized O(1) operations, 🎯 custom hash functions
- [ ] **Trees & BST**: 🎯 All traversals (BFS/DFS, pre/in/post-order, level-order), AVL rotations, Segment trees, Binary Indexed Trees (Fenwick), Red-Black tree concepts
- [ ] **Heap / Priority Queue**: 🎯 Top-K elements, K-way merge, heap-sort, median of stream, custom comparators
- [ ] **Trie**: 🎯 Prefix matching, auto-complete engines, word search optimization, wildcard matching
- [ ] **Graphs**: 🎯 BFS/DFS traversals, Topological Sort, Dijkstra's, Bellman-Ford, MST (Prim's & Kruskal's), Union-Find with rank & path compression

#### 🧮 Advanced Data Structures

- [ ] **Disjoint Set (Union-Find)**: Rank-based union, path compression, applications (connected components, cycle detection)
- [ ] **Segment Tree**: Range sum/min/max queries, lazy propagation, persistent segment trees
- [ ] **Fenwick Tree (BIT)**: Point updates, prefix queries, 2D BIT
- [ ] **LRU / LFU Cache**: 🎯 Implement from scratch (HashMap + Doubly Linked List), eviction policies
- [ ] **Skip List**: Probabilistic data structure, O(log n) search/insert, used in Redis/LevelDB
- [ ] **Bloom Filter**: Probabilistic membership testing, false positives, use cases (caching, distributed systems)

#### 🔁 Algorithmic Patterns

- [ ] **Sliding Window**: 🎯 Fixed size, variable size, with hash map counting, minimum window substring
- [ ] **Two Pointers**: 🎯 Opposite direction (sorted arrays), same direction (fast/slow), three-sum pattern
- [x] **Binary Search**: 🎯 On sorted arrays, on answer space (minimize maximum, maximize minimum), rotated sorted arrays
- [ ] **Recursion & Backtracking**: 🎯 Permutations, combinations, subsets, N-Queens, Sudoku solver, constraint propagation
- [ ] **Greedy Algorithms**: Interval scheduling, activity selection, Huffman coding, jump game, greedy proof techniques
- [x] **Merge Intervals Pattern**: 🎯 Interval merging, insertion, intersection — extremely common in interviews
- [ ] **Matrix Traversal**: Spiral order, diagonal traversal, island problems, flood fill

#### 🧩 Dynamic Programming (Senior Depth)

- [ ] **1D DP**: 🎯 Climbing stairs, house robber, coin change, word break, longest increasing subsequence
- [ ] **2D DP**: 🎯 Grid paths, longest common subsequence, edit distance, interleaving strings
- [ ] **Knapsack Variants**: 0/1 knapsack, unbounded knapsack, partition equal subset sum, target sum
- [ ] **DP on Strings**: Palindrome problems, regex matching, wildcard matching, distinct subsequences
- [ ] **DP on Trees**: Tree diameter, max path sum, house robber on trees, re-rooting technique
- [ ] **Interval DP**: Matrix chain multiplication, burst balloons, optimal BST
- [ ] **Bitmask DP**: Travelling salesman, partition into K equal subsets, assignment problem
- [ ] **State Machine DP**: 🎯 Buy/sell stock series (cooldown, transaction limits, fees)

#### 🔤 String Algorithms

- [ ] **Pattern Matching**: KMP algorithm, Rabin-Karp (rolling hash), Z-algorithm
- [ ] **Suffix Structures**: Suffix arrays, suffix automaton, applications in string matching
- [ ] **String Hashing**: Rolling hash, double hashing for collision avoidance

#### 🔢 Advanced Graph Algorithms

- [ ] **Shortest Paths**: Floyd-Warshall (all pairs), A* search, negative cycles (Bellman-Ford)
- [ ] **Network Flow**: Ford-Fulkerson, Edmonds-Karp, max-flow min-cut theorem
- [ ] **Strongly Connected Components**: Tarjan's algorithm, Kosaraju's algorithm
- [ ] **Bipartite Matching**: Hungarian algorithm, hopcroft-karp
- [ ] **Eulerian Path/Circuit**: Hierholzer's algorithm, conditions for existence

#### 🔢 Bit Manipulation & Math

- [ ] **Bit Operations**: 🎯 XOR tricks (single number), bit counting, power of 2, bit masks for subsets
- [ ] **Math & Number Theory**: Modular arithmetic, GCD/LCM (Euclidean), Sieve of Eratosthenes, fast exponentiation
- [ ] **Combinatorics**: nCr/nPr computation, Pascal's triangle, Catalan numbers

### 💾 Phase 2 — Data & SQL

> **Focus**: At 5+ YOE, you're expected to design schemas, tune queries that handle millions of rows, and articulate trade-offs between consistency and performance.

<details>
<summary><b>🔍 Expand/Collapse Database Sub-topics</b></summary>

#### 🛢️ SQL Fundamentals & Advanced Queries

- [ ] **CRUD Operations**: Basic queries, constraints (`NOT NULL`, `UNIQUE`, `CHECK`, `FOREIGN KEY`), cascading rules
- [ ] **Joins**: 🎯 Inner, Left, Right, Full Outer, Self, Cross Joins — know when each is appropriate and performance implications
- [ ] **Aggregations & Grouping**: `GROUP BY`, `HAVING`, correlated subqueries, derived tables
- [ ] **Common Table Expressions (CTEs)**: 🎯 Non-recursive CTEs for readability, recursive CTEs for hierarchical data (org charts, bill of materials)
- [ ] **Window Functions**: 🎯 `ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG/LEAD`, running totals, moving averages, `PARTITION BY` + `ORDER BY`
- [ ] **Advanced SQL Patterns**: `LATERAL JOIN`, `GROUPING SETS` / `ROLLUP` / `CUBE`, `MERGE` / `UPSERT`, `EXCEPT` / `INTERSECT`
- [ ] **Set Operations**: UNION vs UNION ALL performance, combining result sets efficiently

#### 🏗️ Database Design & Modeling

- [ ] **Normalization**: 1NF through 3NF, BCNF, when to denormalize and why (read-heavy vs write-heavy)
- [ ] **Data Modeling Patterns**: 🎯 Star schema, Snowflake schema, SCD (Slowly Changing Dimensions) Types 1/2/3/4
- [ ] **Entity Relationship Design**: Cardinality, junction tables, polymorphic associations, self-referential relationships
- [ ] **Schema Evolution**: 🎯 Zero-downtime migrations, expand-contract pattern, backwards-compatible column additions, online DDL

#### ⚡ Performance Tuning (Senior Depth)

- [ ] **Indexing Strategies**: 🎯 B-Tree vs Hash vs GIN vs GiST, composite indexes (column order matters!), covering indexes, partial indexes, expression indexes
- [ ] **Query Optimization**: 🎯 Reading `EXPLAIN ANALYZE` output, sequential scan vs index scan, bitmap scans, index-only scans, query plan caching
- [ ] **Execution Plan Analysis**: Cost estimation, row estimation errors, join strategies (nested loop, hash join, merge join), when the planner gets it wrong
- [ ] **Partitioning**: Range, list, hash partitioning, partition pruning, sub-partitioning, when to partition vs when to shard
- [ ] **Connection Management**: Connection pooling (PgBouncer, pgpool-II), connection limits, transaction pooling vs session pooling

#### 🔒 ACID & Transactions (Senior Depth)

- [ ] **ACID Properties**: 🎯 Atomicity, Consistency, Isolation, Durability — real failure scenarios for each
- [ ] **Isolation Levels**: 🎯 Read Uncommitted, Read Committed, Repeatable Read, Serializable — phantom reads, dirty reads, non-repeatable reads
- [ ] **Locking Mechanisms**: Shared locks, exclusive locks, row-level vs table-level, deadlock detection, advisory locks
- [ ] **Optimistic vs Pessimistic Locking**: 🎯 Version columns, `SELECT FOR UPDATE`, trade-offs in high-contention scenarios

#### 🐘 PostgreSQL Deep Dive

- [ ] **Architecture**: 🎯 MVCC (Multi-Version Concurrency Control), Write-Ahead Logging (WAL), shared buffers, bgwriter, checkpointing
- [ ] **Monitoring & Diagnostics**: `pg_stat_statements`, `pg_stat_activity`, `pg_stat_user_tables`, lock monitoring, slow query logging
- [ ] **Maintenance**: `VACUUM` (regular vs full), `ANALYZE`, autovacuum tuning, table bloat detection
- [ ] **Advanced Features**: `JSONB` querying & indexing (GIN), Full-Text Search (`tsvector`, `tsquery`), `LISTEN/NOTIFY`, extensions (`pgvector`, `PostGIS`, `pg_trgm`)
- [ ] **Replication**: Streaming replication, logical replication, read replicas, failover strategies
- [ ] **Backup & Recovery**: `pg_dump`, `pg_basebackup`, continuous archiving (WAL archiving), point-in-time recovery (PITR)

#### 🐬 MySQL Essentials

- [ ] **Architecture**: Storage Engines (🎯 InnoDB vs MyISAM trade-offs), buffer pool, redo/undo logs
- [ ] **Features**: Indexing (clustered vs secondary), transactions, replication (async, semi-sync, group replication)
- [ ] **MySQL vs PostgreSQL**: 🎯 Feature comparison, when to choose which, migration considerations

#### 🧊 Database Internals Concepts

- [ ] **Write Path**: WAL → Memtable → SSTable flush, compaction strategies (size-tiered, leveled)
- [ ] **Buffer Pool Management**: LRU eviction, clock sweep, dirty page flushing

- [ ] **Encryption in Transit**: 🎯 TLS 1.3, certificate management, Let's Encrypt, certificate pinning, HSTS
